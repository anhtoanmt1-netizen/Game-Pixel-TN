# ETERNAL PIXEL – Prototype (Giai đoạn 1)

Chạy cục bộ (ES module cần server, không mở trực tiếp file):
    python3 -m http.server 8080
Rồi mở http://localhost:8080

Triển khai: đẩy toàn bộ thư mục lên GitHub, bật GitHub Pages (branch main, thư mục root).

Điều khiển: WASD di chuyển | J hoặc click quái để đánh | 1 Fireball | Space né | Tab khóa mục tiêu | Q Auto
Điện thoại: joystick trái, nút Đánh / Lửa / Né / Auto bên phải.
